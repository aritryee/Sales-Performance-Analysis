# SALES PERFORMANCE ANALYSIS

## Overview
This project analyzes sales and profit data using Excel to identify high-performing categories and regions.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts

## Key Insights
- Technology category generated the highest profit.
- Sales performance varied significantly across regions.
- Business insights were derived to support data-driven decision-making.

## Outcome
This project demonstrates basic business analytics and consulting-style problem-solving skills.
